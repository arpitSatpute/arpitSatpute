## About Me

I'm a software engineer specializing in blockchain technology and full-stack development. With expertise spanning Web3 applications, microservices architecture, and scalable backend systems, I focus on building secure, efficient, and production-ready solutions.

**Core Competencies:**
- **Blockchain Development:** Smart contracts (Solidity), DeFi protocols, NFT ecosystems, and Web3 integrations
- **Backend Engineering:** Microservices architecture with Spring Boot, RESTful APIs, and distributed systems
- **Full-Stack Development:** React-based frontends, Node.js backends, and modern JavaScript/TypeScript

Currently focused on engineering high-performance Web3 applications and exploring advanced blockchain architectures including Layer 2 scaling solutions and zero-knowledge proofs.

- IPFS integration for immutable product provenance and metadata

**Stack:** Solidity, Foundry, React, IPFS, OpenZeppelin

- Custom Python AI engine with XGBoost for real-time risk scoring and APY prediction

- Automated capital reallocation based on AI-generated strategies

**Stack:** Solidity, Foundry, Python, React, Polygon
